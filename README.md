# Liniya

//RUSSIAN

Линия - современный и минималистичный Todo-менеджер, созданный для удобного планирования задач и достижения целей. Интуитивный интерфейс, гибкая организация дел и ничего лишнего. Наведи порядок в планах, сосредоточься на главном и двигайся к цели - шаг за шагом.

Я делаю сделал это в первую очередь для себя,но решил поделиться и для тех, кому нужен удобный список дел без сложных настроек и лишних кнопок. Открыл приложение, записал задачу — и можно заниматься своими делами.

Что это за приложение спросите вы?
Линия - менеджер задач для компьютера. Главная идея — понятный интерфейс, в котором легко ориентироваться и приятно работать каждый день.

Проект ещё развивается, поэтому внешний вид и возможности со временем могут меняться.

Как запустить проект?
Если хотите запустить приложение из исходного кода, установите Node.js и выполните в папке проекта:
npm install
npm run dev

На чём сделано:
React, TypeScript и Vite.

Ошибки и предложения
Если заметили ошибку или хотите предложить идею, напишите в разделе Issues.\

//ENGLISH

Liniya is a modern and minimalist Todo manager designed for convenient task planning and goal achievement. An intuitive interface, flexible task organization, and nothing superfluous. Get your plans in order, focus on what’s important, and move towards your goal — step by step.

I created this primarily for myself, but I decided to share it with those who need a convenient to‑do list without complex settings and unnecessary buttons. Open the app, write down a task — and you can get on with your own activities.

What kind of app is this, you might ask?
Line is a task manager for computers. The main idea is a user‑friendly interface that’s easy to navigate and pleasant to work with every day.

The project is still under development, so the appearance and features may change over time.

How to run the project?
If you want to run the application from the source code, install Node.js and run the following commands in the project folder:
npm install
npm run dev

What it’s built with:
React, TypeScript and Vite.
