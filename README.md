# Линия — настольный менеджер задач для Windows

«Линия» — локальное приложение для цепочек задач. Интерфейс остаётся на React + TypeScript + Vite; Electron добавляет настоящее окно Windows, системный трей, нативные уведомления и запуск вместе с Windows.

## Версия 2.1.1

В этой версии исправлено переполнение названий цепочек и счётчиков прогресса в боковой панели. Чтобы обновить установленное Electron-приложение, собери новый установщик по инструкции ниже и установи его поверх предыдущей версии. Перед обновлением рекомендуется экспортировать резервную копию данных.

## Быстрый запуск в режиме разработки

Требуется Node.js 20.19+ или 22.12+. Node.js 26 тоже подходит для установки и сборки. Само упакованное приложение запускается на встроенной версии Node.js, которая входит в Electron.

1. Распакуй проект в обычную папку.
2. Дважды нажми `start.bat` (или `start-desktop.bat`).
3. При первом запуске npm установит зависимости. После этого откроется отдельное окно «Линия».

Альтернатива в терминале:

```powershell
npm install
npm run desktop:dev
```

Браузерный запуск сохранён отдельно в `start-browser.bat`. Через терминал его можно запустить так:

```powershell
npm run dev
```

## Создать установщик Windows

1. Запусти `build-installer.bat` или выполни:

```powershell
npm install
npm run dist:win
```

2. После завершения открой папку `dist`.
3. Запусти файл установщика `Линия Setup 2.1.1.exe`.
4. После установки можно запускать «Линию» через ярлык на рабочем столе или в меню Пуск.

Для переносной сборки без обычной установки:

```powershell
npm run dist:portable
```

## Системный трей

- Закрытие крестиком и сворачивание окна по умолчанию скрывают приложение в трей.
- Нажатие на значок «Линии» открывает окно.
- Контекстное меню значка позволяет открыть приложение, включить/отключить запуск вместе с Windows, изменить поведение сворачивания или полностью выйти.
- Чтобы завершить приложение, нажми правой кнопкой мыши на значке «Линии» рядом с часами и выбери «Полностью выйти».

В настройках приложения также доступны переключатели «Запускать вместе с Windows» и «Сворачивать в трей».

## Напоминания

В деталях задачи появилось поле «Напомнить в». Укажи дату и время — приложение покажет системное уведомление Windows. Напоминания продолжают работать, когда окно скрыто в трее.

Чтобы уведомления переживали перезагрузку Windows, включи «Запускать вместе с Windows». При входе в систему приложение восстановит сохранённые напоминания.

**Ограничение:** после команды «Полностью выйти» или завершения процесса приложения уведомления не работают до следующего запуска. Приложение должно оставаться запущенным в трее. При старте уведомления, пропущенные за последние 24 часа, показываются один раз; более старые пропуски не воспроизводятся, чтобы не создавать поток устаревших уведомлений.

В Windows отображение уведомлений зависит также от системных настроек «Не беспокоить» и разрешений уведомлений. Для корректного системного имени и значка рекомендуется проверять уведомления в установленной версии приложения, а не только в режиме разработки.

## Данные и совместимость

- Задачи и настройки интерфейса хранятся локально в IndexedDB/локальном хранилище Chromium.
- Настройки трей/автозапуск и очередь напоминаний сохраняются в пользовательской папке данных Electron.
- Сервер, аккаунт и облачная синхронизация не требуются.
- Существующий экспорт JSON и импорт резервных копий сохранены.
- Существующие цепочки из браузерной версии автоматически не копируются в Electron, потому что браузер и настольное приложение имеют отдельные локальные хранилища. Перед переходом экспортируй данные в браузере, затем импортируй JSON в установленной версии «Линии».

## Стек

- React + TypeScript + Vite
- Zustand
- Electron 45.2.3
- electron-builder 26.18.1 (NSIS installer)

Electron реализует tray и нативные уведомления через официальные системные API. Renderer изолирован от Node.js: `contextIsolation` включён, `nodeIntegration` выключен, а доступ к функциям приложения идёт через ограниченный preload API.
